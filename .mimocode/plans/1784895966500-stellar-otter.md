# Plano: Animação de transição contínua Hero → Navbar flutuante

## Visão geral

Transformar a troca binária da navbar (`scrolled: boolean`) em uma **transição contínua dirigida pelo scroll**. Conforme o usuário rola a página nos primeiros 120px, um único valor de progresso `0→1` coordena duas animações simultâneas:

1. **A notch do SVG `clipPath` fecha** — o recorte na parte superior da Hero (onde ficam os links da navbar) diminui suavemente até desaparecer, como se a Hero "fechasse" atrás da navbar.
2. **A navbar emerge** do recorte e se transforma no card flutuante — top, padding, border-radius, background, blur e box-shadow interpolam progressivamente.

Uma fonte de verdade (`--nav-progress`), duas animações coordenadas, sem bibliotecas externas.

## Arquitetura

```
Scroll (0..120px)
      │
      ▼
  rAF loop → setProgress(0..1)   ← uma única atualização por frame
      │
      ├──► CSS vars na <nav>     → interpola geometria/estilo da navbar via calc()
      └──► setAttribute('d', …)  → morph da notch no clipPath SVG
```

### 1. `notchPath.ts` (novo util)

```typescript
// Easing smooth (cubic-bezier simplificado)
export const easeInOut = (t: number): number =>
  t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;
```

**Interpolação** (p=0 → notch original; p=1 → notch achatada):
- Paredes esquerda/direita do notch: `x_left = 0.121042 → 0.146`, `x_right = 0.798030 → 0.773` (convergem para a borda)
- Floor do notch: `y = 0.084875 → 0` (sobe até o nível do topo)
- Cantos do floor: `y` → `0` (achatam completamente)

### 3. `Navbar.tsx` — scroll-driven progress

```typescript
const [progress, setProgress] = useState(0);
const prefersReduced = useMemo(
  () => matchMedia('(prefers-reduced-motion: reduce)').matches, []
);

useEffect(() => {
  const SCROLL_RANGE = 120; // px de scroll para transition completa

  const update = () => {
    const raw = Math.min(window.scrollY / SCROLL_RANGE, 1);
    const p = prefersReduced ? (raw > 0 ? 1 : 0) : easeInOut(raw);
    setProgress(p);
    // Atualiza o path do SVG
    if (pathRef.current && !prefersReduced) {
      pathRef.current.setAttribute('d', buildNotchPath(p));
    }
  };

  let ticking = false;
  const onScroll = () => {
    if (!ticking) {
      requestAnimationFrame(() => { update(); ticking = false; });
      ticking = true;
    }
  };

  window.addEventListener('scroll', onScroll, { passive: true });
  update(); // inicial: se refresh mid-scroll
  return () => window.removeEventListener('scroll', onScroll);
}, [prefersReduced]);

// No JSX:
<nav className="navbar" style={{ '--nav-progress': progress } as React.CSSProperties}>
```

### 4. `Navbar.css` — interpolação via CSS variables

```css
.navbar {
  /* ...propriedades base (p=0)... */
  --nav-progress: 0;

  top: calc(0px + var(--nav-progress) * 8px);
  padding-top: calc(30px - var(--nav-progress) * 16px);   /* 30 → 14 */
  padding-bottom: calc(var(--nav-progress) * 14px);        /* 0 → 14 */
  padding-left: calc(40px - var(--nav-progress) * 20px);    /* 40 → 20 */
  padding-right: calc(40px - var(--nav-progress) * 20px);
  width: calc(100% - var(--nav-progress) * 40px);
  max-width: 1410px;
  border-radius: calc(var(--nav-progress) * 15px);
  background: rgba(255, 255, 255, calc(0.75 * var(--nav-progress)));
  backdrop-filter: blur(calc(12px * var(--nav-progress)));
  border: 1px solid rgba(255, 255, 255, calc(0.5 * var(--nav-progress)));
  box-shadow: 0 calc(var(--nav-progress) * 4px) 24px rgba(0, 0, 0, calc(0.08 * var(--nav-progress)));
  
  /* Sem transition para as props animadas — o rAF drive é contínuo */
  /* Manter transitions curtas só para hover/color */
  transition: color 0.2s ease, background-color 0.2s ease;
}
```

**Nota sobre box-shadow**: em engines que não suportam `calc()` dentro de `rgba()`, usar um pseudo-elemento `::after` com `opacity: var(--nav-progress)` e o box-shadow fixo como fallback.

## Casos de borda

| Caso | Solução |
|---|---|
| `prefers-reduced-motion: reduce` | Snap `--nav-progress` para `0` ou `1`; não mutar o path `d` do SVG; manter o feel binário |
| Mobile (≤768px) — `ul` escondida | Desabilitar a animação do path `d` (notch é irrelevante sem links visíveis); deixar a navbar animar sozinha |
| Refresh no meio da página (`scrollY > 0`) | Chamar `update()` no mount para inicializar `progress` corretamente — sem flash da notch aberta |
| `backdrop-filter` perf | Ativar `blur` apenas quando `progress > 0.05`; abaixo disso usar `backdrop-filter: none` para evitar GPU layers desnecessárias |
| Resize/orientation | Coords do path são viewBox-relative (0..1), então são resize-safe; o scroll range (120px) é fixo |

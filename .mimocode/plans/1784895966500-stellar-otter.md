# Plano: Preloader GSAP + React para Brothers_Tech

## Visão Geral

Criar um preloader animado para a landing page `landing_page_2/` usando React + TypeScript + Vite + GSAP. A animação desenha o contorno das letras "BROTHERS TECH" progressivamente e depois revela o preenchimento, fazendo transição suave para o conteúdo principal.

## Contexto do Projeto

- **Projeto atual**: HTML/CSS/JS puro na raiz (landing page do Caio)
- **Área de trabalho**: `landing_page_2/` com pasta `assets/`, `css/`, `js/` (vazias)
- **SVGs disponíveis**: 
  - `assets/logo_2/` — paths simples com `fill="#2F2F42"` (ideal para animação)
  - `assets/logo_1/` — SVGs com `<mask>` (exportados do Figma, mais complexos)
- **Framework escolhido**: React + TypeScript + Vite

## Etapas de Implementação

### 1. Setup do Projeto Vite + React + TS

Inicializar um projeto Vite dentro de `landing_page_2/`:

```bash
cd landing_page_2
npm create vite@latest . -- --template react-ts
npm install
npm install gsap
```

Isso vai gerar a estrutura padrão do Vite (`src/`, `public/`, `index.html`, `tsconfig.json`, etc.) dentro de `landing_page_2/`.

### 2. Criar o Componente SVG do Logo

**Arquivo**: `src/components/Preloader/LogoSvg.tsx`

- Extrair os paths dos SVGs da pasta `assets/logo_2/`
- Montar um único `<svg>` com dois `<g>`:
  - `<g id="stroke-layer">` — paths com `fill="none"` + `stroke` + `strokeWidth`
  - `<g id="fill-layer">` — mesmos paths com `fill="#2F2F42"` (inicialmente invisível)
- Adicionar `data-letter` em cada path para facilitar seleção no GSAP
- Adicionar `data-row="brothers"` ou `data-row="tech"` para aplicar cores corretas
- Layout: "BROTHERS" na primeira linha, "TECH" na segunda, centralizados
- **Cores confirmadas pelo usuário**:
  - BROTHERS: stroke e fill em `#2F2F42` (navy escuro)
  - TECH: stroke e fill em `#3B5998` (azul médio)

**Letras necessárias (de logo_2)**:
- Row 1 "BROTHERS": B, R, O, t, h, e, R-1, s
- Row 2 "TECH": t_v2, e-1, C, h-1

**Cores da imagem de referência**:
- BROTHERS (contorno/fill): `#2F2F42` (navy escuro)
- TECH (contorno/fill): `#3B5998` (azul médio)

### 3. Componente Preloader

**Arquivo**: `src/components/Preloader/Preloader.tsx`

- Estado `isVisible` controlando a visibilidade do preloader
- Overlay full-screen com `background: white` e `z-index: 9999`
- Centraliza o `LogoSvg`
- Quando a animação termina, seta `isVisible = false` e chama callback `onComplete`
- Prop `onComplete: () => void` para o componente pai saber quando mostrar o conteúdo

### 4. Lógica de Animação GSAP

**Arquivo**: `src/components/Preloader/preloaderAnimation.ts`

Função `createPreloaderAnimation(svgElement: SVGSVGElement, onComplete: () => void)`:

```
Timeline:
1. 0.00s — Tela branca, logo invisível
2. 0.10s — Stroke layer aparece (opacity 0→1)
3. 0.15s–1.40s — Paths desenhados via strokeDashoffset (length→0)
   - duração: 1.2s por path
   - stagger: 80ms entre letras
   - ease: "power2.out"
4. 1.45s — Fill layer aparece (opacity 0→1, 250ms)
5. 1.50s — Stroke layer Some (opacity 1→0, 200ms)
6. 1.60s — Scale bounce (1 → 1.02 → 1, 200ms)
7. 1.90s — Fade-out do preloader overlay (opacity 1→0, 400ms)
8. 2.10s — Conteúdo principal entra (opacity + translateY)
```

**Técnicas GSAP**:
- `gsap.registerPlugin()` (não precisa de plugins extras, GSAP core basta)
- Calcular `getTotalLength()` de cada path
- Setar `strokeDasharray = length` e `strokeDashoffset = length` no estado inicial
- Animar `strokeDashoffset: 0`
- Usar `gsap.timeline()` com `.to()` encadeados

### 5. Hook usePreloader

**Arquivo**: `src/hooks/usePreloader.ts`

- Retorna `{ isPreloading: boolean, preloaderRef: React.RefObject<HTMLDivElement> }`
- Gerencia o ciclo de vida: mount → animação → complete
- Usa `useEffect` para disparar a animação quando o componente monta
- Cleanup: mata a timeline no unmount

### 6. Integração no App

**Arquivo**: `src/App.tsx`

- **Escopo desta entrega**: apenas o preloader
- Conteúdo placeholder para testar a transição (será substituído pela landing page real depois)

```tsx
function App() {
  const { isPreloading } = usePreloader();
  
  return (
    <>
      {isPreloading && <Preloader />}
      <main style={{ opacity: isPreloading ? 0 : 1, transition: 'opacity 0.5s' }}>
        <h1>Landing page em construção</h1>
      </main>
    </>
  );
}
```

### 7. Estilos

**Arquivo**: `src/components/Preloader/Preloader.css`

- Preloader overlay: fixed, full-screen, white bg, flex center
- SVG responsivo (max-width, auto height)
- Transição suave no conteúdo principal

### 8. Copiar Assets SVG

Mover os SVGs da pasta `assets/logo_2/` para `public/assets/logo_2/` (para acesso via Vite) OU importar direto no componente (via import estático dos paths).

**Decisão**: Vou extrair os paths diretamente no componente `LogoSvg.tsx` como strings de path data — mais leve, sem dependência de arquivos externos, e controle total sobre stroke/fill.
